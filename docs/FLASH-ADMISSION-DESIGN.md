# Flash 自写样本受管接入方案（待批准）

## 首批范围

通用入口仅识别仓库登记的自写 AVM1 SWF，复用现有准备、启动、暂停、观察和停止接口。使用官方 Ruffle Web 0.7.1 自托管包，固定 ZIP SHA-256 为 `ef12edbee135d581a9cd523837d746da30a07a64dbf1cf472d2e472c656f4b5e`，分发所需脚本、WASM、素材清单与上游许可证。准备阶段记录摘要与运行时身份，启动时重新核对。

## 运行时交付建议

首版复用系统已安装的 Edge，浏览器资格按验收构建登记。由 GameQA 查找浏览器和显示不匹配原因，用户无需写配置或另外安装浏览器。Edge 更新后重新验证并登记对应构建。Chrome 157.0.8103.79 保留为预检对照，已经验证的 Edge 构建为 157.0.4341.60。两份可执行文件的 Windows 签名均有效。

正式实现前先验证私有 CDP 管道和所需的启动句柄传递。截图、方向键与探针结果使用已验证的 CDP 能力。Playwright 1.58.0 的本机 `driver/` 实测 102,359,370 字节，作为实验工具保留。正式便携依赖和压缩后增量以构建结果为准。产品开始接受可变浏览器构建或随包分发浏览器之前，需分别验证兼容范围和更新维护方式。

## 输入和进程监督

- 启动固定自写 SWF 的独立 Win32 桌面和 Job。运行数据目录、用户配置与临时文件绑定到测试会话。正式实现须验证原浏览器配置和游戏源目录前后摘要，页面仅加载已登记资源。桌面与 Job 负责隔离输入和回收进程。
- 用真实图像验证首图，首图合格后保持输入暂停。首批动作只开放右方向键与等待。采用现有毫秒动作接口，按唯一请求编号记录，动作期间持续确认画面。目标对按下与松开的消费以自写样本画面验证。
- 无效图、取图停更、租约失效与暂停请求均阻止下一次输入。能通信时发松键并等待确认。卡死或失联时，由持有 Job 的上层宿主按单调时钟独立回收。回执分别记录消费、释放确认和目标退出。
- 使用现有截图 3 秒与释放确认 1 秒的判据。采集调用在期限内阻塞与最终进程退出分别计时。探针的 3 秒计时从要求截图开始，记录宿主完成关闭 Job 的实际耗时。

## 实测和正式验收

| 预检 | 观察结果 |
| --- | --- |
| Chrome 与 Edge 正常对照 | 两批均确认连续 320×240 画面，按键使色块 `x=40 → 128`，松开回到 `x=40` |
| Chrome 渲染器失去响应 | 持键且已读取位移截图后暂停隔离进程的渲染器，捕获调用等待。独立宿主两次均在 3,110 毫秒完成关闭，浏览器和已记录子进程均退出 |
| Edge 渲染器失去响应 | 同一故障注入，3,156 毫秒完成关闭，浏览器和已记录子进程均退出 |

三次渲染器故障批只有按下记录，退出后无法确认松键消费。探针使用 Playwright 和本地回环路由。程序实测覆盖见 `<Flash验证目录>/ruffle-preflight-01/supervision-01/audit.json`。

实施后须用真实 MCP 与便携包验证固定浏览器查找、资源完整性、作品被篡改后的拒绝、输入与证据、断联和卡死、重复与过期命令、同台并发会话及原数据摘要。真人键鼠并发、商业 SWF／投影器、其他浏览器构建与存读档由后续独立批次覆盖。
