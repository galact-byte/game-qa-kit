# YU-RIS 进入条件与暂缓记录

## 当前决定

2026-11-19，用户确认保留 YU-RIS 的研究资料，等待以后取得完整可用、允许测试的同引擎游戏再适配。当前不下载开发包、不构建自写场景、不启动原游戏，也没有新增插件或控制支持。

原盘点中的两个目录来自 Translator++ 的同一暂存工程，分别带原程序与翻译补丁。EXE 版本资源可以确认 YU-RIS 标记，但文件残留及 EXE 摘要不能证明完整游戏仍然存在；不再将其作为可用商业验收样本或优先适配依据。盘点中的目录计数作为历史观测保留。

## 可复用的研究

- [官方工程目录说明](https://yu-ris.net/manual/eris/html/tutorial/chap03/01.html)：`system/YSCom/` 提供编译工具，`script/` 存放源脚本，`ysbin/` 是运行时读取的编译输出，`save/` 用于保存。暂存目录中的 `.ybn` 不能替代编译器，也不能直接用来构建自写样本。
- [官方下载页](https://yu-ris.net/download/index.html)：预检时列有 Beta4.7 `0.479/0.14` 稳定版与 Beta4.8 `0.495/0.32` 开发版。仅对稳定包做了 HTTP HEAD，没有下载 ZIP 正文；当时报告大小为 24,929,629 字节，约 23.77 MiB。版本、大小、许可与官方摘要均须在恢复时重新核对。
- [官方发布目录说明](https://yu-ris.net/manual/eris/html/tutorial/chap07/02.html)与[打包说明](https://yu-ris.net/manual/eris/html/tutorial/chap07/03.html)可作为运行组件和开发组件区分的参考，不代表已获修改或再分发许可。
- 限定本地搜索未找到 YSCom 或官方开发包，只找到提取／Hook 工具。搜索未涵盖全部磁盘与压缩包，不能据此断言本机绝无编译器。

## 恢复条件

先确认新游戏确实完整、引擎构建可核实，并明确原文件、存档和测试权限。需要额外软件时，重新核对来源、版本、许可和占用，再取得相应下载批准；EasyRPG 的下载授权不覆盖本引擎。

之后先在任务目录中准备自写场景与明确的保存路径。只读核查组件后，按零输入有效首图、失焦更新、遮挡取图、正常输入和松键、故障回收的顺序做后台预检；首图纯黑或无效时停手，不发送动作。预检结果成立后再确定正式适配器设计，不能把消息投递或工具识别当作游戏消费输入的证据。
