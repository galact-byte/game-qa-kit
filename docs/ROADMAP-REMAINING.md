## 后续推进顺序

1. Metal GPU 读回、过滤路径与冻结后重新露出诊断均已取得原生证据，默认产品验收仍失败。已知参数对照没有解决问题，继续须有可区分呈现／合成／采集的新观测或真实 GPU 桌面对照，不以重复诊断阻塞其他独立工作。
2. 补齐原生 Godot 运行时和可交互 macOS 桌面后，完成 arm64 试点与权限相关验收。
3. X11 已按批准设计实现，下一步执行独立云端原生验收；Wayland 与其他架构按真实环境依次推进。
4. 每个引擎的商业、玩法、稳定性和真人范围按支持表记录，不为清空路线图而扩大支持结论。
