# 路线图剩余项与进入条件

本表对应 [ROADMAP](ROADMAP.md#当前执行优先级) 的当前进度与推进顺序：先收口当前 Windows 后台窗口代理接入，再逐步实现检查点／双分支，随后按组件与样本条件处理其他余项，最后集中做普通桌面与真人体验。macOS／Linux 普通桌面、真实 GPU、系统授权、真实游戏与集中真人体验后置，不影响其他独立工作；审批、环境和样本边界不能用单元测试代替，缺条件的项目保留明确阻碍。当前有 Windows 和尚未核实桌面条件的 Kali 虚拟机，没有 Mac。
