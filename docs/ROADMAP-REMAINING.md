# 路线图剩余项与进入条件

本表对应 [ROADMAP](ROADMAP.md) 的当前进度与跨平台推进顺序。常规实现、回归与证据整理持续推进；下表中的审批、运行环境和样本边界不能用本地单元测试代替。真人体验按既有决定统一后置。

## 后续推进顺序

1. Metal 读回诊断已确认 GPU 纹理有新内容；默认与诊断截图仍重复。继续区分 drawable 呈现与系统采集输出，不重复已否定的 stdin 开关。
2. 补齐原生 Godot 运行时和可交互 macOS 桌面后，完成 arm64 试点与权限相关验收。
3. X11 按已形成的具体设计批准结果实施；Wayland 与其他架构按真实环境依次推进。
4. 每个引擎的商业、玩法、稳定性和真人范围按支持表记录，不为清空路线图而扩大支持结论。
