## 后续推进顺序

1. Metal GPU 读回、过滤路径与冻结后重新露出诊断均已取得原生证据，默认产品验收仍失败。已知参数对照没有解决问题，继续须有可区分呈现／合成／采集的新观测或真实 GPU 桌面对照，不以重复诊断阻塞其他独立工作。
2. Godot 固定 no-focus 组件的 arm64 自写短场景受管 MCP 源码／冻结验收已完成并合入主线，默认验证开关仍关闭。后续按实际需求扩展，普通桌面与权限相关验收需可交互 macOS 环境，不以自写样本结果开放商业构建。
3. X11 已完成本轮源码／冻结云端产品验收并合入主线；普通桌面、Wayland 与其他架构按真实环境依次推进。
4. 当前先完成主线五目标候选的构建、随包内容和兼容范围复核，再按明确版本批准正式发布。各引擎的商业、玩法、稳定性和真人范围继续按支持表记录，不为清空路线图而扩大支持结论。
