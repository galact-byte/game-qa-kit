源码基线两路线墙钟 512.49→245.37 秒（本批 2.09 倍）；正式包新批为 559.23→268.68 秒（本批 2.08 倍）。正式包四支各三轮、93 动作，84 检查点逐图审阅、1773 项证据核对与 1167 项收尾检查通过；原件、1 号检查点及外部巡检身份未变，9 号档排除，10 个已记录精确进程身份均退出。首次正式包串行失败原样保留：截图中途停住后心跳过期，底层原因未唯一定位；新批未复现不等于修复。并发上限、长期稳定性及集中真人体验仍待验。30 分钟不自动追加，2 小时暂不安排。

macOS／Linux 普通桌面、真实 GPU、系统授权与集中真人体验后置，不影响其他独立工作；真实游戏按样本条件推进。审批、环境和样本边界不能用单元测试代替。当前有 Windows 和尚未核实桌面条件的 Kali 虚拟机，没有 Mac。
