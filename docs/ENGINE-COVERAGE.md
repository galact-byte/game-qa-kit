# 游戏引擎支持范围

这里列出 AI 后台操作游戏的支持情况。支持范围以实际测过的游戏和版本为准；能识别引擎或截取画面，不代表已经能控制游戏。

本文下表的游戏后台控制实证均来自 Windows。独立 macOS arm64 实验分支已用固定 no-focus Godot 构建和自写场景通过完全遮挡后的观察新帧、移动／等待、暂停／失租松键、全程焦点及回收检查；尚未接入 macOS 正式受管 MCP 入口，不计入下表产品支持，详见[原生验证记录](X11-GODOT-VALIDATION.md)。已发布的 macOS／Linux 通用测试版只开放配置、存档快照和已有证据复核等公共功能，不继承下表的控制支持；参见[通用版构建与验证](UNIVERSAL-BUILD.md)。开发中的 macOS arm64 采集分支已在源码与冻结成品分别验证 AppKit 自写窗口的完整遮挡新图、尺寸变化、观察／人工标记和退出，以及真实组件故障与回收；Metal 仍有重复计数，完整产品验收未通过，首次授权／撤权与真实游戏未验。具体范围见[接入设计](MACOS-ARM-CAPTURE-DESIGN.md)。
