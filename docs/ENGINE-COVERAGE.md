# 游戏引擎支持范围

这里列出 AI 后台操作游戏的支持情况。支持范围以实际测过的游戏和版本为准；能识别引擎或截取画面，不代表已经能控制游戏。

| 游戏引擎／平台 | 已验证过的操作 | 使用条件 |
|---|---|---|
| RPG Maker MV／MZ | 示例工程的开始游戏、角色移动和菜单操作 | 直接启动仅支持已登记的示例工程与运行时；商业游戏需要单独验证 |
| RPG Maker VX Ace | 示例工程的开始游戏、角色转向和菜单；另有商业样本通过读档与移动测试 | 直接启动仅支持已登记的示例工程；商业样本尚未接入该入口 |
| Unity | 已测游戏的菜单、剧情交互；部分样本已验证角色移动 | 需要匹配游戏版本与输入系统，直接启动仅支持已登记的游戏版本；详见 [Unity 适配说明](../plugins/unity/README.md) |
| Wolf RPG | 已有移动、菜单、战斗及存读档实测，具体范围因样本而异 | 直接启动时仅验过官方范例的启动、标题操作和预览；商业版本需独立接入 |
| HSP3 | 固定自写样本的后台启动、位移与菜单。独立桥另验画布及原生按钮点击，以及商业样本的标题和读取菜单 | 直接启动仅接受登记的 HSP 3.7 x86 运行时与仓库自写字节码。商业构建沿用[专用入口](../plugins/hsp/README.md) |
| DuckStation／PS1 | 指定游戏的移动、存读档与首场战斗 | 仅验证指定模拟器版本，尚不支持从工具直接启动；不通用于其他 PS1 模拟器 |
| SRPG Studio | 已测游戏的标题、环境设置与返回操作 | 仅支持已登记构建；游戏鼠标、移动与存读档未验 |
| RPG Maker XP／VX、2000／2003 | 仅能识别引擎 | 暂不支持后台操作 |
| Godot 4 | 自写样本的后台启动与移动；独立桥另验了按钮点击和确认 | 仅支持已登记的 4.5.1 运行时与自写样本；不支持商业 PCK，见[接入说明](../plugins/godot/README.md) |
| Ren'Py | 自写场景的后台启动与移动；独立桥另验确认、取消与存读档 | 仅支持登记的 8.3.2 运行时和自写样本；暂停只停止合成输入，不启动商业工程，见[接入说明](../plugins/renpy/README.md) |
| TyranoScript | 自写场景的后台启动、Enter 确认和等待；独立桥另验正常存读档 | 仅支持登记的 Ver5／Electron 7.1.2 组件与自写场景，见[接入说明](../plugins/tyrano/README.md) |
| Emuera | 自写场景的后台启动、Enter 确认和等待。独立桥另验正常存读档 | 仅支持已登记的 1.824／.NET Framework 4.5 构建和自写场景，见 [接入说明](../plugins/emuera/README.md) |
| KiriKiri | 自写 Window 的后台启动、Enter 确认和等待。独立桥另验自写 Window 存读档与自写 KAG 确认 | 直接启动仅接受登记的 2.32.2.426／x86 构建与自写 Window。商用兼容性及诊断记录见[实验说明](../plugins/kirikiri/README.md) |
| Flash／SWF | 自写 AVM1 样本通过 Ruffle Web 的后台预检 | 暂无工具入口。Adobe 独立播放器及 Ruffle 桌面版的后台首图仍待验证 |
| Unreal 等 | 暂无 | 暂不支持后台操作 |

从界面启动游戏的具体条件见 [游戏接入说明](GAME-ADMISSION.md)。同一引擎的不同版本或插件可能需要不同适配，不能用一个样本的结果推断所有游戏均可用。
