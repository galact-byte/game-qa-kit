## KiriKiri 自写 KAG 工程可以后台操作

在 v0.3.0 的自写 Window 实验基础上，本版增加了 KAG 工程的后台确认和等待。确认操作经过游戏原来的按键处理，等待不发送按键；可以连续取得画面，并核对游戏是否处理了按下和松开。

本次还补充了独立启动宿主和写入检查，并修正了有 `data.xp3` 时的项目选择方式。对于固定运行时遇到的 CP932 脚本转换问题，提供显式启用的独立 Unicode 补丁，保留原归档不变；脚本加载与输入只在自写工程中验证通过。

## 故障处理修复

- 动作已经执行、后续却只截到黑屏时，保留这次动作的执行记录并停止输入，避免丢失已发生的操作。
- 取图失败后再次恢复，直接返回取图错误，不再一直等到超时。
- 补齐守卫接手后发生宿主故障时的错误记录，便于区分启动、输入和取图问题。

## 支持范围

KiriKiri 仍是实验支持，仅限固定的 32 位运行时和自写工程，尚未接入主界面的通用启动入口。

商业 KAG 的启动检查仍遇到音频初始化问题，本版没有解决商业游戏后台控制，也没有解决音频播放。其他引擎的版本和条件见[引擎支持范围](https://github.com/galact-byte/game-qa-kit/blob/v0.3.1/docs/ENGINE-COVERAGE.md)。

## 下载和升级

下载 `game-qa-kit-v0.3.1-windows-x64.zip`，完整解压后打开 `GameQA.exe`。MCP 客户端使用同目录的 `GameQA-MCP.exe`，无需另外安装 Python。

支持 Windows 10／11 x64。升级时解压到新目录，再迁移自己的 `profiles/` 和 `data/`，保留新包的 `_internal`。压缩包不含游戏、外部桥组件或 OCR 模型；下载文件可用 `SHA256SUMS.txt` 校验。
