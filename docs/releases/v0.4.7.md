本版修正 VX Ace 实验桥在心跳发布失败后的截图处理，并完善后台输入与采集操作的回归检查。

## 心跳发布失败时跳过观察截图

VX Ace 桥通过替换状态文件发布心跳。替换失败时，此前没有将失败结果正确传回帧循环，仍可能继续生成观察截图；现在会在该帧跳过观察截图，避免心跳未成功发布时继续增加截图开销。正常的心跳节流与成功发布不受影响。

这项修正不延长两秒心跳期限，也不改变动作超时、按键释放或进程回收规则。它修复的是已复现的心跳发布失败分支，不代表其他原因引起的截图阻塞已经解决。

## 回归检查更准确

后台点击和拖拽检查不再将 Windows 拒绝读取光标位置误算为“光标未移动”；无法读取时会明确记录未验证。采集界面的键盘启停检查会等待按钮恢复可操作，再确认实际采集会话已经停止。这些调整仅影响测试判定，不改变后台输入或界面交互方式。

## 升级与兼容范围

本版不改变配置、存档或控制协议格式，也不新增引擎或商业构建支持。Windows 便携版已包含桥文件，使用新包接入即可；单独部署 VX Ace 桥的用户需要同步更新 `GameQaBridge.rb`，运行中的旧进程不会自动加载新脚本。升级前请先结束旧的受管会话。

其他平台仍不提供 VX Ace 后台控制，不能将本次 Windows 验证当作跨平台实测。具体支持范围以[引擎支持表](https://github.com/galact-byte/game-qa-kit/blob/v0.4.7/docs/ENGINE-COVERAGE.md)为准。
