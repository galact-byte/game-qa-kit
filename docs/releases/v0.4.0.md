## 七类自写样本可以从统一入口启动

此前，Godot、Ren'Py、TyranoScript、Emuera、KiriKiri、HSP 和 Flash 的样本需要使用各自的实验入口，部分引擎在主界面中只能识别。本版将已验证的固定样本接入「AI 后台接入」，可以从界面或 MCP 检查组件、准备测试副本、启动和停止会话。

启动后先显示画面，输入保持暂停。确认画面正常、绑定会话并恢复输入后，才能操作样本。

| 引擎 | 本版可操作的样本 | 需要准备的组件 |
| --- | --- | --- |
| Godot 4.5.1 | 自写 PCK：方向键移动、松键和暂停预览 | 登记的固定运行时及自写 PCK |
| Ren'Py 8.3.2 | 自写场景：移动、松键和持续取图 | 匹配完整清单的运行组件和场景 |
| TyranoScript Ver5（500）／Electron 7.1.2 | 自写场景：Enter 确认、松键和等待 | 固定组件和场景 |
| Emuera 1.824 | 自写场景：在 WAIT 后取得首图，确认和等待推进 | 固定运行时及本机 .NET Framework 4 C# 编译器 |
| KiriKiri 2.32.2.426 x86 | 自写 Window：Enter 确认、松键和等待 | 固定运行时和样本脚本 |
| HSP 3.7 x86 | 自写样本：角色右移、菜单开关和松键 | 固定 `hsp3.exe` 和 `GameQaHsp.dll` |
| Flash AVM1 | 自写 SWF：右方向键移动、松键和持续取图 | 固定 Edge 157.0.4341.60；Ruffle Web 0.7.1 资源已随包提供 |

以上支持均限于自写样本。组件会按文件摘要检查，版本号相同也可能因构建不同而无法接入；缺少组件时会提示原因，需要自行准备。各引擎的原运行时和编译工具不随包提供。

## Flash 后台运行

Flash 新入口通过 Ruffle Web 和本机 Edge 运行 SWF，使用独立浏览器配置，不依赖浏览器扩展或 Adobe Flash 插件。浏览器在独立 Windows 桌面运行，通过私有管道连接，不开放调试端口。

自写样本已验证连续取图、方向键移动和松开回位。首图无效时不发送输入；渲染器卡住或浏览器退出时，会结束本次会话的进程树。卡死和退出场景下无法确认游戏是否读到松键，结束记录会保留这一结果。

这个入口只接受已登记的 Edge 构建。Edge 自动更新后可能无法接入，需要重新验证。商业 SWF、鼠标、存读档、其他浏览器构建尚未验证；Adobe 独立播放器和 Ruffle 桌面版也不在本次可用范围内。

## 修复

- Godot：租约文件原子更新期间，短暂无法打开文件可能使有效会话被误判为失效。现在对这类打开失败进行有限重试，再检查内容；真正的租约过期仍会停止输入。
- 便携版：补齐独立取图进程的启动入口，解决 Emuera／KiriKiri 等流程在打包后无法按源码方式启动取图进程的问题。
- Flash：复用 Edge 启动时的初始标签页，解决便携版等待额外标签页导致的首图超时。
- Flash：等 SWF 播放、页面导航完成后再聚焦播放器，解决过早聚焦被导航重置、方向键未进入样本的问题。

便携自检也增加了新接入模块、样本和 Flash 资源的检查，Ruffle 的来源与许可证随包附带。

## 其他调整和限制

引擎盘点中重新区分了工具、运行时、游戏子目录和重复程序，补充 EasyRPG、YU-RIS 和 AGE_System 的线索。这些只是识别结果，尚未增加对应的后台控制入口。

KiriKiri 商业 KAG 和音频问题仍未解决，本版通用入口仅支持自写 Window。DuckStation 通用入口也尚未完成，需要固定构建、配套组件、合法 BIOS 和已授权的镜像文件。

新增入口仍属实验支持，其他游戏、其他构建、长期运行和真人同时操作键鼠尚未验证。暂停输入不等于暂停游戏运行；独立 Windows 桌面也不隔离文件、注册表或网络。

## 下载和升级

下载 `game-qa-kit-v0.4.0-windows-x64.zip`，完整解压到新目录后运行 `GameQA/GameQA.exe`。MCP 客户端使用同目录的 `GameQA-MCP.exe`。支持 Windows x64，主程序不需要另外安装 Python；校验文件为 `SHA256SUMS.txt`。

升级前结束旧会话，再迁移自己的 `profiles/` 和 `data/`，并更新 MCP 的程序路径。保留新包的 `_internal` 文件夹。实验样本建议重新准备副本，避免混用新旧桥和宿主。

新增样本的文件和布局见各插件说明，便携包中已入库的样本位于 `GameQA/_internal/plugins/<引擎>/samples/`。检查所需组件后，在「AI 后台接入」选择样本、组件和新的 QA 数据目录即可准备副本。

本次远端构建通过了 100 项接入、会话、MCP 和 GUI 定向回归，以及实际 EXE 自检。各引擎的真实操作验证范围请查对应文档。
