本版补充 Windows 后台窗口采集、专用测试检查点和分支排队，并修复 VX Ace 后台会话的两处心跳恢复问题。

## Windows 后台窗口采集

Windows 可以通过系统采集接口读取后台或被其他窗口遮挡的窗口。只支持保持可见、未最小化的目标窗口；最小化或隐藏时会停止取图，不会把旧画面当作新画面。使用前请安装并启用 Windows 的“图形工具”可选功能。

人工盯屏仍只采集和记录，不会向游戏发送输入。后台窗口采集也不等于后台输入控制；输入仍须使用对应引擎已经验证的接入方式。

同时修正冻结程序自检抢占当前桌面前台的问题。自检使用独立桌面窗口完成验证。

## 专用测试检查点与分支排队

已登记的 VX Ace SDK 和固定 RGSS300 游戏构建，可在 GUI、CLI 或 MCP 中选择独立检查点目录。只接受 `Save01.rvdata2` 至 `Save07.rvdata2`，会在准备时检查内容并展示操作摘要；发现文件在检查后变化会拒绝继续。导入只作用于受管副本，不覆盖原游戏，也不会自动在游戏中读档。

GUI 增加检查点目录选择、清空和重新检查。VX Ace 与 RPG Maker MV／MZ 的受管实例默认静音，不改变系统音量或手动游玩的实例。

MCP 新增 `game_qa_run_queue`，可让独立分支按活动名额排队。创建者持有自己的工作进程和会话；失败、取消或创建者退出时，先处理暂停、松键和进程回收，再允许候补继续。报告只读回看，不恢复已经结束的控制权。

Windows 冻结候选已用固定 RGSS300 样本验证检查点准备、读档、移动、三支排队和退出回收。此范围不代表其他游戏、任意引擎或长时间并行均已通过，也没有可据此承诺的加速倍数。

## VX Ace 心跳恢复

状态文件短暂发布失败时，现在先重试发布，避免每轮重试前的慢截图继续拖延心跳。停止会话时，即使读到过期状态，也会先尝试优先暂停；只有收到新的“已暂停、按键为空”状态，才确认释放成功。持续断线或目标身份不符仍报告失败。

控制心跳的 2 秒期限保持不变。真正过期时仍拒绝新动作；这次修复不扩大可接受的失联时间。

## 下载与升级

Windows x64、macOS x64／arm64、Linux x64／arm64 的包均由正式发布工作流构建。下载与系统架构一致的压缩包，解压后启动其中的程序；已有项目数据目录可以继续使用。升级前请结束旧的受管会话，新建会话使用新包内匹配的插件，不混用新旧桥文件。

需要额外运行组件的引擎仍须按[引擎支持表](../ENGINE-COVERAGE.md)准备对应版本；安装包不包含商业游戏、测试存档或有单独分发限制的运行时。
