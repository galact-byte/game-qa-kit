# v0.4.1 · EasyRPG 自写场景后台接入

本版新增 EasyRPG 自写 RPG Maker 2000 场景的后台接入，并修复同时运行多个受管会话时，取图子进程可能卡在启动阶段的问题。

## ✨ 新增功能

- “AI 后台接入”可以准备并启动随包附带的 EasyRPG 自写 RM2K 场景。首次启动保持输入暂停，取得有效画面后，通过统一 MCP 显式恢复输入；目前支持向右移动和等待。
- 移动、松键和暂停均等待游戏运行时确认，重复请求不会重复执行。两个自写场景会话已验证输入互不串扰，结束后回收各自启动的进程。

## 🛠️ 修复与优化

- 修复无交互取图子进程继承 MCP 标准输入管道后，在多会话情况下可能无法完成启动的问题。
- EasyRPG 的取图失败、请求过期及游戏停帧会停止后续输入并执行回收；已经消费的动作与无法确认的松键分别记录，不把失败伪装成执行成功。
- 修复 EasyRPG 故障后再次手动暂停可能复用旧暂停回执的问题。

## 🔄 使用与兼容性

- 下载并解压 `game-qa-kit-v0.4.1-windows-x64.zip`，运行 `GameQA.exe`，无需另装 Python。
- EasyRPG 入口目前仅接受随包的原样自写样本，以及已登记摘要的独立 `GameQaEasyRpg.exe`。主 ZIP 包含插件、自写样本和许可说明；**不包含独立 EasyRPG 运行时**，需要已有本次验证的本地组件。普通 EasyRPG Player 或其他构建不能直接替代。
- 本次 EasyRPG 验证不覆盖商业游戏、RPG Maker 2003、音频、菜单、其他方向、存读档、长期稳定性或真人键鼠并发。暂停只停止自动输入，游戏仍继续运行；动作时间单位为毫秒。
- 其他引擎沿用 v0.4.0 的组件要求与验证范围。YU-RIS 尚在进入条件核查阶段，本版没有新增其控制能力。旧会话请先停止，解压到新目录后重新准备；无需迁移游戏存档。

## 验证情况

- EasyRPG 源码定向回归 28 项、便携版真实 MCP 7 项通过，覆盖位移与松键、暂停恢复、双会话隔离、篡改拒启、过期请求及故障回收；截图故障收尾另连续复测 3 次通过。
- Python 常规回归 429 项通过、292 项按环境条件跳过；MV/MZ 28 项与 C++ 输入桥检查通过。
- 本次远端发布流程另运行产品入口及生命周期回归，并构建实际 EXE，完成冻结 worker、MCP 与 Qt 窗口自检后才上传发布资产。
