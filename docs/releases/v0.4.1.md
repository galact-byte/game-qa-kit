## EasyRPG 自写场景可以从统一入口启动

本版将 EasyRPG 的自写 RPG Maker 2000 场景接入「AI 后台接入」，可以从界面或 MCP 检查组件、准备测试副本、启动和停止会话。目前可以让角色向右移动，也可以等待一段时间并查看画面。

启动后先显示画面，自动输入保持暂停。确认画面正常、绑定会话并恢复输入后，才能操作样本。暂停只停止自动输入，游戏本身仍会继续运行。

这个入口需要已验证的独立 `GameQaEasyRpg.exe`。插件和自写样本已随包附带，独立运行时不在主 ZIP 中，需要另外准备。工具目录里的普通 EasyRPG Player、其他版本或其他构建不能直接替代；缺少组件或文件不匹配时会提示原因。

本次支持限于自写 RM2K 样本的右移和等待。商业游戏、RPG Maker 2003、音频、菜单、其他方向、存读档、长期运行和真人同时操作键鼠尚未验证。

## 修复

- 同时运行多个后台会话时，取图进程有时无法完成启动，导致后续截图超时。现在已修复这一问题，两个 EasyRPG 样本可以分别操作和关闭。
- EasyRPG 在取图失败后再次手动暂停，有时会无法确认暂停结果。现在会重新等待游戏确认，不再沿用上一次的暂停结果。

移动、松键和暂停的结果由游戏运行时确认，重复提交同一次请求不会重复执行。取图失败、请求过期或游戏停止响应时，会停止后续输入；无法确认松键时会保留实际结果，并回收本次启动的进程。

其他引擎的组件要求与支持范围沿用 v0.4.0。

## 下载和升级

下载 `game-qa-kit-v0.4.1-windows-x64.zip`，完整解压到新目录后运行 `GameQA/GameQA.exe`。MCP 客户端使用同目录的 `GameQA-MCP.exe`。支持 Windows x64，主程序不需要另外安装 Python；校验文件为 `SHA256SUMS.txt`。

升级前结束旧会话，再迁移自己的 `profiles/` 和 `data/`，并更新 MCP 的程序路径。保留新包的 `_internal` 文件夹，测试样本请重新准备副本。

EasyRPG 样本位于 `GameQA/_internal/plugins/easyrpg/samples/rm2k/`。在「AI 后台接入」选择这个目录、匹配的运行组件和新的 QA 数据目录，即可准备测试副本。
