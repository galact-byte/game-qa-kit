# v0.4.6 后台启动诊断与会话按钮修正

本版让 Windows 后台消息代理的启动失败更容易排查，并修正后台接入窗口的结束按钮状态。

## 启动失败不再只显示“未就绪”

后台消息代理在初始化时退出后，`background_status` 现在会保留退出码、代理与目标身份。非提权启动还会返回最近的错误文本，便于区分身份检查拒绝等原因；重复查询或停止后仍能回看，新启动会清除上次诊断。

错误文本仅在当前 MCP 内存保留最后 16 KiB，不新增日志文件。代理错误输出统一为 UTF-8，避免中文 Windows 错误说明出现乱码。提权启动仍只返回退出码和通用说明。同用户身份校验、管道访问限制与 UAC 流程不变，不新增 Sandboxie 通用兼容或商业游戏后台输入支持。

## 会话结束后的按钮状态

GUI 轮询到会话结束、失败、清理失败或取消时，现在会及时刷新操作按钮；即使没有新截图，“结束会话”也会禁用，避免继续对已经结束的会话操作。

## 升级与兼容范围

本版不改变配置、存档或控制协议格式。Windows 用户升级前请先结束旧的受管会话，再使用新包；源码方式使用 MCP 的用户需要正常重新连接，已运行的进程不会自动加载更新。

同时补充了分支排队故障组合与 Unity 启动测量的回归测试，没有放宽启动期限、松键确认或进程身份检查。引擎与商业构建的适用范围仍以[引擎支持表](https://github.com/galact-byte/game-qa-kit/blob/v0.4.6/docs/ENGINE-COVERAGE.md)为准。
