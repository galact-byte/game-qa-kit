## macOS Apple Silicon 新增窗口采集

macOS 14 及更新版本的 Apple Silicon 程序包，现在可以截图、持续观察窗口、人工标记疑点并整理证据。采集组件已随包提供，使用时需要授予屏幕录制权限。

这项功能仍属实验支持，目前只在自写测试窗口上验证过遮挡、调整尺寸等情况。Metal 画面仍可能出现重复帧，日常桌面的权限流程和真实游戏尚未验证；使用时请确认截图持续更新，暂不建议用于无人值守巡检。

Linux X11 采集也属默认关闭的实验功能，尚未验证日常桌面或真实游戏。macOS Intel 的可用功能保持不变。

## Godot 截图和动作状态修复

- 修复 Godot 窗口被完全遮挡、暂停自动绘制后，截图无法及时更新的问题。
- 修复动作结束后，查询结果仍可能显示按键按下的问题。
- Windows 版新增对 EXE 内嵌 Godot 游戏包的识别，方便判断引擎；识别成功不代表已支持该游戏的后台控制。

macOS Apple Silicon 另增加固定 Godot 4.5.1 自写场景的后台控制实验，可执行移动、等待和暂停。该入口默认关闭，需要另行准备匹配的测试运行组件，暂不支持商业游戏、其他构建或完整玩法。

升级前请结束旧会话，升级后重新准备引擎测试副本，避免混用新旧组件。
