## macOS Apple Silicon 增加窗口采集

macOS 14 及更新版本的 Apple Silicon 程序包现在可以截图、持续观察窗口、人工标记疑点并归档证据。采集组件已包含在程序包中，无需另外安装 Python 或 Swift；使用时需要按系统提示授予屏幕录制权限。macOS Intel 与 Linux 默认入口继续提供配置、存档快照、已有证据复核和公共 MCP 工具。

这项功能目前仍属实验支持，已验证自写测试窗口被完全遮挡、调整尺寸时的采集，以及异常后的停止和清理。Metal 画面仍可能出现重复帧，日常桌面、首次授权或撤销权限、真实游戏的使用情况尚未验证。使用时请确认截图持续更新，暂不建议依赖它进行无人值守的游戏巡检。

## Godot 截图和动作状态修复

修复 Godot 窗口被完全遮挡、暂停自动绘制后，观察和动作截图无法及时更新的问题。另修复动作已经完成、查询时却仍可能看到按键保持按下的状态。

Windows 版新增对 EXE 内嵌 Godot PCK 的只读识别，方便判断游戏使用的引擎；识别成功不会自动开放该游戏的后台控制。

macOS Apple Silicon 增加固定 Godot 4.5.1 自写测试场景的后台控制实验入口，支持移动、等待、暂停及异常停止时的按键释放和进程清理。此入口默认关闭，需要另行准备匹配的测试运行时，具体要求见下方说明。它不适用于任意商业 PCK；其他构建、存读档、长期运行及与真人键鼠同时操作仍未验证。

## 下载和升级

五种程序包继续使用同一份 `SHA256SUMS.txt` 校验文件，请按系统和芯片选择：

- Windows x64：`game-qa-kit-v0.4.4-windows-x64.zip`，完整解压后打开 `GameQA/GameQA.exe`；MCP 客户端使用同目录的 `GameQA-MCP.exe`。
- macOS Intel：`game-qa-kit-v0.4.4-macos-x64.tar.gz`；Apple Silicon：`game-qa-kit-v0.4.4-macos-arm64.tar.gz`。解压后打开 `GameQA.app`。
- Linux x64：`game-qa-kit-v0.4.4-linux-x64.tar.gz`；arm64：`game-qa-kit-v0.4.4-linux-arm64.tar.gz`。解压后打开 `GameQA/GameQA`。

升级前请结束旧会话，完整解压新包并保留自己的配置和记录。Windows 可迁移原包的 `profiles/` 和 `data/`，保留新包完整的 `_internal` 目录，并更新 MCP 程序路径。macOS 和 Linux 继续使用原有用户数据目录。引擎测试副本请重新准备，避免混用新旧桥组件与会话文件。

macOS 包仍采用临时签名，尚未获得开发者签名或公证。Linux x64 要求 glibc 2.35 或更新版本，arm64 要求 glibc 2.39 或更新版本。Linux X11 采集仍为默认关闭的实验功能，仅在云端测试环境验证过自写窗口；日常桌面、物理 GPU、Wayland 与真实游戏尚未验证。
