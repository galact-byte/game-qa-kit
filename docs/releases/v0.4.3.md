## macOS 和 Linux 提供独立程序包

本版为 macOS Intel、macOS Apple Silicon、Linux x64 和 Linux arm64 分别提供程序包，无需另外安装 Python。Windows x64 ZIP 继续提供，五种程序包使用同一份 `SHA256SUMS.txt` 校验文件。

macOS／Linux 可以使用配置读写、存档快照、已有证据复核和公共 MCP 工具。游戏窗口采集、持续盯屏与引擎后台控制目前仍限 Windows；非 Windows 界面会禁用相应入口并说明原因。

macOS 包采用临时签名，尚未获得开发者签名或公证。Linux x64 要求 glibc 2.35 或更新版本，arm64 要求 glibc 2.39 或更新版本；包内附中文字体。Wayland、较旧系统以及用户日常桌面使用尚未验证。

## Windows 新增 GameMaker 与 Bakin 的限定接入

GameMaker 的固定自写 YYC 场景可以从「AI 后台接入」准备和启动，支持右移、等待、暂停和恢复。样本源码随包提供，匹配的 `gameqa-gamemaker.exe` 和 `data.win` 须另外准备；工具会核对摘要。商业程序、VM 构建、其他动作与存读档尚未验证。

Bakin 新增一个已登记的 2.5.1.0 导出构建接入。匹配游戏与四个桥组件须另行提供，原游戏和存档不随程序包分发。实时状态与租约改用共享内存，减少启动、加载期间对高频文件替换的依赖；升级时必须同步桥组件与宿主，并重新准备会话。

Bakin 已实测标题操作、新游戏确认、加载审核与恢复、控制权交接及对白推进。剧情全白转场会触发现有画面保护并暂停自动操作；四方向自由移动、实机强杀父进程回收与完整玩法仍未验收。共享内存通道已完成阶段验证，长期稳定性仍需验证。其他 Bakin 构建不在支持范围内。

## 下载和升级

Windows 下载 `game-qa-kit-v0.4.3-windows-x64.zip`，完整解压后打开 `GameQA/GameQA.exe`；MCP 客户端使用同目录的 `GameQA-MCP.exe`。

macOS 按芯片选择 `game-qa-kit-v0.4.3-macos-x64.tar.gz` 或 `game-qa-kit-v0.4.3-macos-arm64.tar.gz`，解压后打开 `GameQA.app`。Linux 按架构选择 `game-qa-kit-v0.4.3-linux-x64.tar.gz` 或 `game-qa-kit-v0.4.3-linux-arm64.tar.gz`，解压后打开 `GameQA/GameQA`。

升级前结束旧会话，保留自己的配置与数据。Windows 可以迁移原包的 `profiles/` 和 `data/`，同时保留新包完整的 `_internal` 目录，并更新 MCP 程序路径。macOS 数据位于用户的 Application Support 目录；Linux 使用 XDG 目录。引擎测试副本请重新准备，避免混用不同版本的桥、登记清单与会话记录。
