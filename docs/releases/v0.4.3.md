## 新增 macOS 和 Linux 程序包

除了 Windows x64，现在也提供 macOS Intel／Apple Silicon、Linux x64／arm64 程序包，无需另外安装 Python。Linux 包内附中文字体。

macOS 和 Linux 本版可以管理配置、备份存档、复核已有截图与日志，以及使用公共 MCP 工具。窗口截图、持续盯屏和引擎后台控制仍限 Windows，界面会提示哪些功能暂不可用。

macOS 程序尚未获得开发者签名或公证。Linux x64 需要 glibc 2.35 或更新版本，arm64 需要 glibc 2.39 或更新版本；日常桌面使用仍待验证，具体兼容范围见下方说明。

## Windows 新增 GameMaker 和 Bakin 实验接入

GameMaker 的指定自写测试场景可以从「AI 后台接入」启动，执行右移、等待、暂停和恢复。需要另行准备配套运行组件，暂不支持商业游戏或其他构建。

Bakin 新增对一个指定的 2.5.1.0 游戏构建的接入，已验证标题操作、新游戏、加载后查看画面、控制权交接和对白推进。游戏与桥组件需另行准备，其他构建暂不支持。

Bakin 的剧情全白转场仍会触发画面保护并暂停自动操作，自由移动、完整流程和长期运行尚未验证。升级时请同步更新 Bakin 桥组件并重新准备测试副本。
