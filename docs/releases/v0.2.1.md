## Windows 便携版

从这个版本开始，可以直接下载 Windows 程序使用，不再需要安装 Python 或运行 BAT 脚本。

包内有两个入口：

- `GameQA.exe`：打开巡检界面。手动玩游戏时可以自动留图、标记疑点，再按规则筛选截图、整理复核日志。
- `GameQA-MCP.exe`：供 AI 客户端调用。MCP 配置中的 `command` 填写这个文件的完整路径即可，无需额外启动参数；也可以继续用 `GAMEQAKIT_PROFILE` 指定配置。

配置保存在程序旁的 `profiles/`，默认记录目录为 `data/<配置名>/`。如果原有配置已经指定了其他数据目录，仍使用原来的路径。

## 打包和启动修复

- 补齐界面和基础截图所需的依赖，并区分主窗口、盯屏进程和游戏会话进程，避免后台任务启动时又弹出一个主窗口。
- 发布前检查实际 EXE 的资源文件、后台子进程、MCP 连接和界面启动，检查通过后才生成下载包与校验文件。

后台控制沿用此前已验证的插件和游戏构建。Wolf 的统一接入尚未包含在这个版本中。

## 下载和升级

下载 `game-qa-kit-v0.2.1-windows-x64.zip`，完整解压到可写目录后打开 `GameQA.exe`。请保留旁边的 `_internal` 文件夹，不能只复制 EXE。

升级时请解压到新目录，再迁移自己的 `profiles/` 和 `data/`，以免覆盖原有记录。需要从源码运行的用户仍可沿用原来的方式。

## 使用限制

支持 Windows 10／11 x64。程序尚未签名，Windows 可能提示发布者未知；可通过本仓库来源和 `SHA256SUMS.txt` 核对下载文件，无需关闭安全软件。

便携包不含游戏、存档、个人配置、商业运行组件或 OCR／YOLO 模型。基础截图、人工标记和规则筛选不需要模型；自动筛出的疑点仍需人工确认。后台控制需要另外准备匹配的桥或运行组件，具体版本见[引擎支持范围](https://github.com/galact-byte/game-qa-kit/blob/v0.2.1/docs/ENGINE-COVERAGE.md)。取不到有效画面时应停止输入。

项目源码使用 MIT 许可，便携包中的 PyQt6、Qt 等组件遵守各自许可。许可文件和对应源码取得方式见包内的 `第三方组件说明.md` 与 `_internal` 许可目录；本版本项目源码及构建脚本可从 Release 的标签源码下载。
