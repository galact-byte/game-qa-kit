## ✨ Windows 便携版

这次提供解压即用的 Windows x64 程序：**不必安装 Python，也不必再运行 BAT**。

- **`GameQA.exe`**：盯屏巡检控制台。手动玩游戏时自动留图，支持截图、人工标记疑点、规则筛选和汇总复核日志。
- **`GameQA-MCP.exe`**：供 MCP 客户端直接启动的独立入口，无需配置 Python 路径。
- 配置保存在程序旁的 `profiles/`；没有另设数据目录时，新记录保存在 `data/<配置名>/`。已有配置里的显式路径继续有效。

## 🛠️ 打包与启动修正

- 随包提供界面和基础留图所需依赖，并保留后台子进程的显式分派，避免打包后把盯屏／受管 worker 错开成第二个主窗口。
- 打包流程自检实际 EXE 的插件资源、冻结子进程、MCP 握手与工具列表、Qt 窗口，再生成 ZIP 和 SHA-256 校验文件；自检失败不会发布。
- 沿用原有人工盯屏和已登记的实验后台控制能力，没有把所有引擎改成自动接管，也没有夹带尚未验收的 Wolf 受管接入实现。

## 📦 下载与使用

下载 **`game-qa-kit-v0.2.1-windows-x64.zip`**，完整解压到可写目录，再双击 `GameQA.exe`。请保留 `_internal`，不能只拿走一个 EXE。

MCP 客户端的 `command` 可直接填写 `GameQA-MCP.exe` 的完整路径，无需额外 args；需要时仍可通过 `GAMEQAKIT_PROFILE` 指定配置。

升级建议解压到新目录，再复制自己的 `profiles/` 与 `data/`，不要直接覆盖旧记录。源码运行方式仍保留。

## 🔄 兼容性与已知边界

- 面向 **Windows 10／11 x64**。程序目前未做代码签名，系统可能提示发布者未知；请核对本仓库来源和 `SHA256SUMS.txt`，不需要关闭安全软件。
- 不附带游戏、存档、个人配置或商业运行组件。AI 后台接入仍需匹配的原生桥、Unity 组件、NW.js 或 RGSS 等已有产物，并且仅对已登记构建开放；**不是任意游戏的一键后台控制器**。
- OCR／YOLO 模型和可选机器学习依赖不在便携包内。基础截图、人工标记和规则候选不依赖这些模型；自动疑点仍只是候选，不是已确认缺陷。
- 游戏的后台绘制和取图兼容性各不相同，失联、黑图或画面停更时应停止输入。具体已验范围和未验项目请看 [引擎覆盖表](https://github.com/galact-byte/game-qa-kit/blob/v0.2.1/docs/ENGINE-COVERAGE.md)。

项目源码继续采用 MIT；组合便携发行包含 PyQt6／GPLv3、Qt 和其他上游组件，遵守各自许可。完整许可和对应源码取得方式随包提供于 `第三方组件说明.md` 与 `_internal` 的许可目录；本版本源码和构建配方可从本 Release 的标签源码下载。
