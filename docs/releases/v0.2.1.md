## Windows 版可以直接解压使用

从这个版本开始，无需安装 Python 或运行 BAT 脚本，下载 Windows 便携包即可使用巡检界面。手动玩游戏时，可以自动留图、标记疑点，再筛选截图、整理复核日志；也可以通过包内的 MCP 程序连接 AI 客户端。

配置与默认巡检记录保存在程序旁，方便一起保留和迁移。已有配置指定的数据目录继续有效。

## 启动问题修复

补齐界面和基础截图所需的依赖，修复启动后台任务时可能再次弹出主窗口的问题。

## 使用前请留意

便携版支持 Windows 10／11 x64，程序尚未签名，系统可能提示发布者未知。请完整解压使用，不能只复制 EXE；升级时保留自己的配置和记录。

基础截图、人工标记和规则筛选无需另装模型，筛出的疑点仍需人工确认。程序包不含游戏、存档或外部游戏运行组件；后台控制仍限此前已验证的游戏版本和插件，本版尚未包含 Wolf 的统一接入。
