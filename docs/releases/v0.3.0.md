## Wolf 官方范例接入主界面

这个版本将 Wolf RPG 官方范例接到「AI 后台接入」。此前需要单独准备和启动插件，现在可以从界面创建测试副本、启动会话，再通过界面或 MCP 查看画面、操作标题菜单和暂停输入。

接入仍要求匹配的范例版本和桥组件。商业 Wolf 游戏不在这个入口的支持范围内。

## 新增五类引擎的实验桥

新增 Godot 4、Ren'Py、TyranoScript、Emuera 和 KiriKiri 的实验桥，供适配开发和自写工程测试使用。它们使用统一的 MCP 控制接口，但各自的加载方式、运行版本和输入能力不同。

这些桥只在指定版本的自写工程中通过验证，本版尚未把它们接入主界面的通用启动流程。准备组件和启动方式需按对应插件文档操作，不能直接选择任意商业游戏运行。

## 文档调整

重新整理了首页、入门说明、MCP 配置和引擎支持范围，将日常使用与适配开发资料分开，方便查找启动方式和各引擎的限制。

## 下载和升级

下载 `game-qa-kit-v0.3.0-windows-x64.zip`，完整解压后打开 `GameQA.exe`，无需安装 Python。MCP 客户端使用同目录的 `GameQA-MCP.exe`。

升级请解压到新目录，再迁移自己的 `profiles/` 和 `data/`，保留新包的 `_internal` 文件夹。包内不含游戏、存档、外部桥组件或 OCR 模型。

支持 Windows 10／11 x64。接入前请核对[引擎支持范围](https://github.com/galact-byte/game-qa-kit/blob/v0.3.0/docs/ENGINE-COVERAGE.md)，下载文件可用同页的 `SHA256SUMS.txt` 校验。
