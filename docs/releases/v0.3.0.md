## 下载与升级

下载 `game-qa-kit-v0.3.0-windows-x64.zip`，完整解压后双击 `GameQA.exe`，无需安装 Python。MCP 客户端使用同目录的 `GameQA-MCP.exe`。

升级请解压到新目录，再迁移自己的 `profiles/` 和 `data/`；保留 `_internal` 文件夹。不附带游戏、存档、外部桥组件或 OCR 模型。

适用于 Windows 10／11 x64。后台控制仅限已验证的版本和样本，接入前请查看[引擎支持范围](https://github.com/galact-byte/game-qa-kit/blob/v0.3.0/docs/ENGINE-COVERAGE.md)。
