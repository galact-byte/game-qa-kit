## Wolf 官方范例可以从界面接入

现在可以在「AI 后台接入」中为 Wolf RPG 官方范例创建测试副本、启动会话、查看画面和操作标题菜单，也可以随时暂停自动输入。此前这些步骤需要单独准备和启动插件。

该入口需要匹配的官方范例版本和桥组件，暂不支持任意商业 Wolf 游戏。

## 新增五类引擎的实验支持

新增 Godot 4、Ren'Py、TyranoScript、Emuera 和 KiriKiri 的后台控制实验，方便测试自写场景。目前仅验证了指定版本的测试工程，尚不能从主界面直接选择并启动，需要按插件说明准备；这不代表已支持这些引擎的商业游戏。

本版也重新整理了首页、入门说明和 MCP 配置文档，方便分别查找日常使用方法与引擎适配资料。
