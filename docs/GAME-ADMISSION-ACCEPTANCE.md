# 后台操作的真人验收清单

这份清单用于验证：AI 在后台操作游戏时，测试者能否照常在其他应用中打字、按键和拖动窗口。启动、游戏操作、截图和退出检查由执行测试的助手负责，参与者只需判断日常操作有没有受到干扰。

真人验收统一安排在开发和自动预检完成后集中进行。目前以下目标均待参与者确认，自动回归和截图不能代替这一结论。

## 验收目标

同一引擎的不同输入方式需要分别验证，因此 Unity 在此列为四个测试项；日常选用工具时只需查[引擎支持范围](ENGINE-COVERAGE.md)。各项使用已登记的固定版本，由助手准备，不要求参与者安装组件或手写配置。

| 测试项 | 助手执行的游戏操作 | 参与者重点观察 |
|---|---|---|
| SRPG Studio | 启动、标题菜单、进入设置、返回和退出 | 游戏是否突然置顶，键盘或鼠标是否受干扰 |
| Unity：传统输入接口 | 标题点击、进入剧情、推进对白 | 其他应用的打字和拖动是否正常 |
| Unity：Input System | 等待自然到标题、进入房间、推进对白 | 后台点击是否影响其他应用 |
| Unity：IL2CPP／Input System | 标题、难度选择、剧情对白 | 其他应用的按键是否混入游戏 |
| Unity：Rewired | 标题、难度、新游戏加载、剧情对白 | 加载和后台输入是否影响当前工作 |
| RPG Maker MV | 开始游戏、角色右移、菜单 | 真人按键与 AI 输入能否各自生效 |
| RPG Maker MZ | 开始游戏、角色右移、菜单 | 与 MV 分开确认，不复用其结果 |
| RPG Maker VX Ace | 开始游戏、角色转向、菜单 | 后台转向和菜单是否影响当前工作 |
| Wolf RPG 官方范例 | 启动到有效画面、等待标题、方向键切换选项 | 启动和操作期间是否干扰当前工作 |
| Godot 4.5.1 自写样本 | 后台启动、查看首图、向右移动、暂停和退出 | 方向键是否混入游戏，游戏是否抢占当前窗口 |
| Ren'Py 8.3.2 自写样本 | 后台启动、查看首图、向右移动、暂停和退出 | 真人打字和方向键能否照常使用 |
| TyranoScript Ver5／Electron 7.1.2 自写样本 | 后台启动、查看首图、确认推进、暂停和退出 | 在其他应用敲 Enter 是否照常，测试画面是否误推进 |
| Emuera 1.824／.NET Framework 4.5 自写样本 | 后台启动、查看首图、确认推进、暂停和退出 | 在其他应用敲 Enter 是否照常，测试画面是否误推进 |

所有目标还需检查暂停松键、预览更新、关闭观察窗口及最终退出。Unity 的输入暂停不代表游戏逻辑冻结；VX Ace 当前示例地图的水面不能通行，角色转向不算位移。Wolf 的受管玩法和存读档，以及其他目标未列出的玩法，不在本次已验证范围内。

## 一次集中完成的步骤

1. 助手按同样顺序完成自动预检，确认能够启动、取得画面、正常操作、松键并退出。停止所有移动系统光标、切换前台或模拟桌面键鼠的脚本，一次只运行一个目标。
2. 参与者打开便签或常用编辑器，保持它在前台。助手启动后台游戏，参与者观察是否弹出窗口、抢焦点或遮挡当前工作。
3. 参与者连续打字，使用方向键、回车和 Esc，再按住鼠标左键拖动普通窗口。同时助手通过后台控制桥执行表内操作，并核对每一步的新画面。双方分别检查：游戏输入是否影响其他应用，真人输入是否混入游戏。
4. 助手暂停并确认目标松键，参与者继续在其他应用操作。随后关闭观察窗口，确认游戏仍由创建者管理；最后由创建者结束游戏，助手核对进程退出、原数据和副本变化。

出现黑图、画面停更、失联或输入干扰时，停止该目标并保留记录。后续重试应另记结果，不能覆盖本次失败。

## 每个目标的记录

- 测试时间、参与者、游戏版本和证据目录。
- 启动或加载期间：有无弹窗、遮挡、抢焦点、鼠标干扰。
- 后台操作期间：打字、按键、鼠标移动和拖动是否正常。
- 真人输入是否混入游戏。
- 新画面、暂停松键、观察窗口关闭、创建者退出及原数据核对的证据。
- 结论：通过／失败／未执行。未参与不能记为通过。

## 尚未纳入本次验收的范围

HSP 和 DuckStation 缺少原固定样本或匹配组件，历史独立接入记录不能替代当前启动入口的验收。商业版本的其他玩法、存读档、长期稳定性及其他游戏版本按具体任务另验。

接入条件见[游戏接入说明](GAME-ADMISSION.md)，技术范围见各[插件文档](BACKGROUND-CONTROL.md#在副本里接入)，后续安排见[路线图](ROADMAP.md)。
