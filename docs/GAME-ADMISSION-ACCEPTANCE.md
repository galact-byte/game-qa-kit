# 后台接入集中真人验收清单

本清单保留给全部可执行开发完成后的集中验收，当前均为待参与者确认。自动回归、真实游戏截图与前台采样不能替代真人输入体验；未迁入的后端不列入已可验目标。接入条件和限制以[接入说明](GAME-ADMISSION.md)及[引擎覆盖表](ENGINE-COVERAGE.md)为准。

## 当前可验目标

| 固定目标 | 助手已验证的操作范围 | 本次真人重点 |
|---|---|---|
| 已登记 SRPG Studio x86 构建 | 受管启动、正常菜单操作、暂停松键、退出核查 | 启动与运行是否遮挡、抢焦点或干扰实体键鼠；游戏鼠标和玩法不在已验范围 |
| 已登记 Unity Mono／旧 Input《Taimashi》 | 暂停首图、标题点击进入剧情、当前预览、退出核查 | 老师在其他应用操作时，后台菜单／剧情输入能否独立工作 |
| MV 1.6.1 固定 SDK＋已登记 NW.js | 暂停标题、开始、地图右移、菜单和当前预览 | 其他应用中的实体输入是否影响后台角色；后台输入是否影响老师 |
| MZ 1.8.0 固定 SDK＋已登记 NW.js | 暂停标题、开始、地图右移、菜单和当前预览 | 同上，独立记录，不能用 MV 的结果代替 |
| 固定 VX Ace SDK＋RGSS301 | 暂停标题、开始、转向、菜单和当前预览 | 后台转向与菜单是否独立；水面不可通行，不把坐标未变报作回归 |

## 一次集中执行的顺序

1. 助手先为每个目标完成同样顺序的自动预检，确认暂停首图、正常操作、松键和退出核查；停止所有会移动系统光标、置前窗口或模拟桌面键鼠的脚本。一次只运行一个测试目标。
2. 老师打开便签或常用编辑器并保持它在前台。助手从受管入口启动后台会话，老师观察游戏窗口是否突然出现、置顶或遮挡现有工作。只读检查与连接已有会话也应不抢焦点。
3. 老师连续输入一段文字、使用方向键和确认／取消键，并按住鼠标左键拖动一个普通窗口；同时助手只通过已绑定的后台桥执行该目标表内的正常操作。老师检查文字、光标、拖动和当前窗口是否受干扰；助手读回每一步操作图，检查老师的实体输入是否混入游戏。
4. 助手暂停并确认松键后，老师继续使用其他应用；随后检查观察窗口关闭不会结束其他创建者的游戏，由创建者结束会话才回收目标。助手核对目标退出、原数据一致及副本变化记录。出现黑图、停更、失联或输入干扰即停止该目标，不恢复重试来覆盖失败记录。

启动、等待、动作与退出由助手操作；老师只判断自己的实体输入与日常操作是否被干扰。运行中的观察图应显示当前场景，不能拿停在标题的旧图作通过证据。Unity 的输入暂停不等于整个引擎仿真暂停。

## 每个目标的确认记录

- 时间、参与者、固定构建与证据批次：待填写。
- 启动／等待期间是否抢焦点、遮挡或干扰鼠标：待确认。
- AI 后台操作期间，老师打字、按键、拖动是否正常：待确认。
- 老师实体输入是否混入后台游戏：待确认。
- 逐步操作图、暂停松键、观察者关闭、创建者退出与原数据核对：链接到同批证据。
- 结论：通过／失败／未执行；失败保留原批次，不由后续成功改写。

## 尚不能安排为已迁入目标的项目

- Unity Mono／新 Input System：旧空白探针的运行副本已回收，现有商业运行库不等于该探针。商业构建的无输入诊断确认第 1 帧首图全黑，约 0.62 秒后才出现 Live2D 启动画面；场景加载与后端初始化不能直接视为有效首图就绪。未通过正式受管入口，未发送游戏输入。
- Unity Rewired 与 IL2CPP／新 Input System：完整复制所需空间分别约 2.56 GiB、12.46 GiB；空间已清理，尚待按顺序迁入并验证完整隔离副本。
- Wolf：官方范例第 0 帧暂停时首图全黑，初始化生命周期阻碍尚未解除。
- HSP／DuckStation：缺少原固定样本与匹配组件，历史 smoke 记录不能代替当前入口验收。

这些阻碍不取消已验证目标的功能，也不扩大为引擎整体不可用。新样本、保存边界、长期负载、虚拟机／Sandbox 或模型方案仍按[路线图](ROADMAP.md)的前置条件推进。
